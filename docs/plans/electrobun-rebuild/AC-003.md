## Goal

Define the tagged union of commands the engine accepts. Scope this ticket to the lifecycle slice only; later waves extend it.

## Files

- `packages/contracts/src/orchestration.ts`

## Acceptance criteria

1. `OrchestrationCommand` is a `Schema.Union` of tagged members, each carrying `commandId`.
2. v1 members: `project.create`, `project.meta.update`, `project.delete`, `session.create`, `session.meta.update`, `session.archive`, `session.unarchive`, `session.delete`, `message.send`, `turn.cancel`.
3. Every command decodes and encodes round-trip in a property test.
4. A helper `commandToAggregateRef(command)` returns `{aggregateKind: 'project' | 'session', aggregateId}` and is exhaustive over the union (no `default` branch that hides a missing case).
