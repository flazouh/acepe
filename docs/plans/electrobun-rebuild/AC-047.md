# AC-047 — Delete Rust, Tauri and cargo

**Wave:** Wave 8 — Cutover  ·  **Size:** M  ·  **Blocked by:** AC-045, AC-046
**Blocks:** nothing

## Goal

Remove the sidecar and the entire Rust toolchain.

## Files

- `packages/desktop/src-tauri/`
- `.github/workflows/`
- `package.json`

## Acceptance criteria

1. `packages/desktop/src-tauri/` is deleted, along with every cargo job in CI.
2. The Tauri entry point and its dependencies are removed from every `package.json`.
3. sea-orm, sqlx and rusqlite are gone; `@effect/sql-sqlite-bun` is the only database path.
4. The repository builds, tests and ships with Bun alone.
5. A tag is cut immediately before deletion so the Rust implementation stays recoverable from git.

## Notes

Cut the tag first. It costs nothing and it is the only way back.

## Definition of done

- All acceptance criteria above pass.
- Colocated `.test.ts` exists beside every new source file.
- `bun run typecheck` and the full test suite pass.
- `god-architecture-check` was run if this ticket touches canonical session state.
