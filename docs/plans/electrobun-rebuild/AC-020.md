# AC-020 — Electrobun shell skeleton, signed

**Wave:** Wave 3 — Shell and first slice  ·  **Size:** L  ·  **Blocked by:** AC-001
**Blocks:** AC-045

## Goal

One window, one RPC round trip, one signed and notarised macOS build. Prove the release pipeline before the port depends on it.

## Files

- `packages/desktop/electrobun.config.ts`
- `packages/desktop/src/bun/main.ts`
- `scripts/build-electrobun.sh`

## Acceptance criteria

1. `electrobun` builds an app that opens a window loading the existing Svelte bundle.
2. A round trip from the webview to the Bun process and back is proven by a test that asserts on the returned value.
3. The macOS build is code-signed and notarised, and the notarisation ticket staples.
4. The Tauri build still works from the same repo. Both pipelines run in CI side by side.
5. The differential updater is configured, and an update from build N to N+1 is demonstrated locally.

## Notes

Do this EARLY, in parallel with Wave 0. Signing and notarisation problems are discovered late and block releases; discovering them now costs days instead of weeks.

## Definition of done

- All acceptance criteria above pass.
- Colocated `.test.ts` exists beside every new source file.
- `bun run typecheck` and the full test suite pass.
- `god-architecture-check` was run if this ticket touches canonical session state.
