# AC-056 — Build electrobun-qa, the preload-based QA driver

**Wave:** Wave 8 · **Size:** L · **Blocked by:** AC-054

Read `docs/plans/electrobun-qa/DESIGN.md` first. It is the spec; this ticket is the build.

## Why this replaces AC-055's approach

AC-055 built a verb CLI (`qa inspect --selector=X`) whose eval bridge times out on every call. Two necessary-but-insufficient fixes are recorded in that ticket. The root problem is architectural: it tries to inject JavaScript that must find its own way home, and `executeJavascript` is fire-and-forget over an encrypted socket.

`AC-055`'s `doctor` verb works and its signed-build gating is correct. Keep both ideas; replace the transport and the CLI shape.

## Build

Create `packages/electrobun-qa` with the layout in the design doc.

1. **Preload** (`src/preload/`). Registers a `qa:*` handler namespace on `window.__electrobunInternalBridge`, which Electrobun already uses for webview tags and drag regions. Handlers: `qa:eval`, `qa:snapshotText`, `qa:snapshotDom`, `qa:click`, `qa:type`, `qa:key`, `qa:scroll`, `qa:waitFor`, `qa:pageInfo`.
2. **Host** (`src/host/`). Bun side. Owns the bridge client, a unix-socket server in the runtime dir, and one session per connected app.
3. **Runtime** (`src/runtime/`). The helper surface from the design table, preloaded into heredoc scripts. `cliLog` is the only output path.
4. **CLI** (`src/cli.ts`). `electrobun-qa run` reads a script on stdin and executes it with helpers in scope. Also `doctor` and `help`.

## Acceptance criteria

1. `electrobun-qa doctor` against a running Acepe build reports window title, url and count, and exits non-zero with a named error when no app is running.
2. This heredoc returns **real DOM text** from the running app, and the output is pasted into the ticket as evidence:
   ```bash
   electrobun-qa run <<'EOF'
   cliLog(await snapshotText())
   EOF
   ```
3. `click({ text: ... })` produces an observable DOM change, verified by a following `snapshotText` in the **same** script.
4. Every helper has a deadline and fails with a named error. No hangs. Prove the timeout path with a test.
5. The preload and host are absent from a signed build. Prove it with a test on the build flag.
6. Zero dependencies beyond Bun and Electrobun.

## Notes

Do not use screenshots for verification anywhere in this ticket. `snapshotText` returns an accessibility-shaped text tree. A screenshot proves a window exists and nothing else; this project already lost time to exactly that ambiguity.

Match ego-browser's helper names where they overlap. The vocabulary transfer is worth more than any naming improvement.

The package must not import anything from `@acepe/*`. It is a general Electrobun tool that we happen to prove against Acepe, and the goal is to propose it upstream.

## Definition of done

- All acceptance criteria pass, with criterion 2's output pasted in.
- AC-050 can run against it.
