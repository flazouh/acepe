# AC-016 — Rust sidecar over stdio JSON-RPC

**Wave:** Wave 2 — Oracle  ·  **Size:** L  ·  **Blocked by:** yes (no blockers)
**Blocks:** AC-017

## Goal

Expose today's Rust handlers as a standalone binary speaking newline-delimited JSON-RPC on stdin and stdout, so the current behaviour can be recorded and replayed against.

## Files

- `packages/desktop/src-tauri/src/bin/sidecar.rs`
- `packages/desktop/src-tauri/src/commands/`

## Acceptance criteria

1. A new binary target starts, reads NDJSON requests, dispatches to the SAME handler functions the Tauri commands call, and writes NDJSON responses.
2. All 230 command names are reachable by name. A test enumerates the Tauri command registry and asserts the sidecar covers every one.
3. Streaming updates that today go out as Tauri events are emitted as NDJSON notifications on the same stdout stream, tagged with the session they belong to.
4. The Tauri app keeps working unchanged; this binary is additive.
5. The binary exits cleanly on stdin EOF.

## Notes

This is the only large Rust edit in the whole project and it is mechanical. It exists purely to be the oracle. Do NOT refactor the handlers while doing it.

## Definition of done

- All acceptance criteria above pass.
- Colocated `.test.ts` exists beside every new source file.
- `bun run typecheck` and the full test suite pass.
- `god-architecture-check` was run if this ticket touches canonical session state.
