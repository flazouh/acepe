# AC-008 — Pure decider and command invariants

**Wave:** Wave 0 — Spine  ·  **Size:** L  ·  **Blocked by:** AC-004
**Blocks:** AC-010

## Goal

Write the pure function that turns a command plus the current read model into events, with all guards factored into named invariants.

## Files

- `packages/server/src/orchestration/decider.ts`
- `packages/server/src/orchestration/commandInvariants.ts`
- `packages/server/src/orchestration/Errors.ts`

## Acceptance criteria

1. `decide(readModel, command): Effect<ReadonlyArray<OrchestrationEvent>, OrchestrationCommandInvariantError>`.
2. The function is PURE apart from id and timestamp generation, which are injected, not called inline. A test runs it twice with the same inputs and gets identical events.
3. Invariants are named and reusable: `requireProject`, `requireProjectAbsent`, `requireSession`, `requireSessionAbsent`, `requireSessionNotArchived`, `requireSessionArchived`.
4. The switch over command types is exhaustive with no `default` branch.
5. Every invariant has a test proving both the pass and the fail path.
