## Acceptance criteria

1. From a running Electrobun build: create a project, create a session, send a message, and see a streamed reply render in the transcript.
2. The path is command to decider to event store to projector to projection to snapshot to RPC to Svelte atom. No shortcuts, no direct database reads from the UI.
3. Streaming tokens arrive as events and land in the transcript in sequence order.
4. Killing and restarting the Bun process mid-stream recovers the transcript from projections with no lost or duplicated message.
5. The harness grades this flow against the recorded reference fixture and passes.
