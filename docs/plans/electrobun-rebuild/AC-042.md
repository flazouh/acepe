# AC-042 — Transcript viewport on projections

**Wave:** Wave 7 — Frontend  ·  **Size:** L  ·  **Blocked by:** AC-041, AC-014
**Blocks:** AC-046

## Goal

Point the viewport at the messages projection, keeping the DOM-authority scroll model exactly as it is.

## Files

- `packages/desktop/src/lib/components/transcript/`
- `packages/desktop/src/lib/viewport/`

## Acceptance criteria

1. Follow-release stays gated on user-intent events (wheel, touch, key, scrollbar pointerdown) plus the time-boxed programmatic guard. It is NOT gated on generic scroll.
2. Content-visibility re-measure bursts do not strand follow above the edge. Verify with a live rAF trace, not a screenshot.
3. JS scroll anchoring is retained; WebKit still has no `overflow-anchor`.
4. Scroll behaviour is verified on all three webview engines before this ticket closes.

## Notes

The existing scroll model is load-bearing and was expensive to get right. Port it as-is; do not take the opportunity to improve it.

## Definition of done

- All acceptance criteria above pass.
- Colocated `.test.ts` exists beside every new source file.
- `bun run typecheck` and the full test suite pass.
- `god-architecture-check` was run if this ticket touches canonical session state.
