# AC-045 — Packaging, signing and the differential updater

**Wave:** Wave 8 — Cutover  ·  **Size:** M  ·  **Blocked by:** AC-020, AC-022
**Blocks:** AC-047

## Goal

Make the Electrobun build the shipping build on macOS, with updates flowing.

## Files

- `scripts/build-electrobun.sh`
- `.github/workflows/`

## Acceptance criteria

1. Signed, notarised, stapled macOS builds produced in CI.
2. The differential updater ships a binary patch between consecutive releases and an end-to-end update is demonstrated.
3. Windows builds run on Edge WebView2.
4. Linux ships with bundled CEF, or Linux is explicitly dropped and that decision is recorded in an ADR.

## Inherited platform gaps

- **Windows has no terminal.** AC-053 replaced `node-pty` with `Bun.Terminal`, which is POSIX only in Electrobun 1.18. Decide whether Windows ships without a terminal, waits for ConPTY support, or keeps a Rust PTY for that platform alone.
- **Linux needs bundled CEF.** WebKitGTK cannot do Electrobun's webview layering, so the 14MB bundle claim does not survive Linux.

## Notes

WebKitGTK cannot handle Electrobun's webview layering, so CEF is the recommended Linux path and it changes the bundle-size argument.

## Definition of done

- All acceptance criteria above pass.
- Colocated `.test.ts` exists beside every new source file.
- `bun run typecheck` and the full test suite pass.
