# AC-049 — Migrate packages/desktop off neverthrow and zod

**Wave:** Wave 7 — Frontend · **Size:** L · **Blocked by:** AC-044

## Goal

AC-044 finished the expand phase and migrated `packages/ui` and `packages/website`. `packages/desktop` still has **240 files importing `neverthrow`** and **12 importing `zod`**. This ticket is the migrate and contract phases for desktop.

## Files

- `packages/desktop/src/**` — everything except the six files listed below
- `package.json`, `packages/desktop/package.json` — dependency removal, contract phase only

## Acceptance criteria

1. Migrate in batches by directory, each batch its own commit, with `bun run --cwd packages/desktop typecheck` green between batches. Do not attempt all 240 files in one pass.
2. Use `@acepe/effect-result` helpers from AC-044 rather than inventing new conversions.
3. **Do not modify these six files.** They carry uncommitted work that predates this project: `converted-session-types.ts`, `file-index-types.ts`, `session-jsonl-types.ts`, `session-update-types.ts`, `tauri-command-client.ts`, `user-settings-types.ts`, all under `packages/desktop/src/lib/services/`. If a batch cannot land without touching one, stop and report which file and why.
4. CONTRACT: once no importer remains, drop `neverthrow` and `zod` from every `package.json`, and `bun run --cwd packages/effect-result cli` passes.
5. The full desktop test suite passes at every batch boundary, not only at the end.

## Notes

The AC-044 lane read the instruction "do not touch `packages/desktop/src/lib/services`" as a prohibition on all of `packages/desktop`, which is why it stopped. The restriction is only those six files.

This is the Asana-shaped work: mechanical, file-independent, and the existing desktop test suite is a free oracle. Run several agent lanes over disjoint directories.

## Definition of done

- All acceptance criteria above pass.
- `bun run typecheck` and the root test suite pass.
