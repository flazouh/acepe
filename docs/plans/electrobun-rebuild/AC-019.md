# AC-019 — RPC contract over the Electrobun boundary

**Wave:** Wave 3 — Shell and first slice  ·  **Size:** M  ·  **Blocked by:** AC-003, AC-015
**Blocks:** AC-022

## Goal

Define the single typed surface between the Bun process and the webview: dispatch a command, read a snapshot, subscribe to events.

## Files

- `packages/contracts/src/rpc.ts`
- `packages/server/src/rpc/handlers.ts`
- `packages/desktop/src/lib/rpc/client.ts`

## Acceptance criteria

1. Three primitives only: `dispatch(command)`, `snapshot(sessionId)`, `events(fromSequence)` as a stream. Resist adding a fourth.
2. Requests and responses are Schema-encoded; failures are `Schema.TaggedError` and survive the boundary with their tag intact.
3. The Electrobun RPC schema is GENERATED from the contract package, not hand-written, so the two cannot drift.
4. The client reconnects and resumes `events(fromSequence)` from its last seen sequence with no gap and no duplicate.
5. A test kills the Bun process mid-stream and asserts the client recovers to a consistent state.

## Notes

230 Tauri commands collapse into three primitives because everything that mutates is now a command and everything that reads is now a projection. If a feature seems to need a fourth primitive, it is usually a missing command.

## Definition of done

- All acceptance criteria above pass.
- Colocated `.test.ts` exists beside every new source file.
- `bun run typecheck` and the full test suite pass.
- `god-architecture-check` was run if this ticket touches canonical session state.
