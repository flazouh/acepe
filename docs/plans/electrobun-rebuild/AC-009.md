# AC-009 — Pure projector and in-memory read model

**Wave:** Wave 0 — Spine  ·  **Size:** L  ·  **Blocked by:** AC-004
**Blocks:** AC-010

## Goal

Write the pure fold from events to the in-memory read model the decider reads.

## Files

- `packages/server/src/orchestration/projector.ts`
- `packages/server/src/orchestration/Schemas.ts`

## Acceptance criteria

1. `projectEvent(readModel, event): Effect<OrchestrationReadModel, OrchestrationProjectorDecodeError>`.
2. `createEmptyReadModel(nowIso)` returns the zero value.
3. Replaying the same event sequence from empty always yields an identical read model. Prove it with a property test over generated event sequences.
4. Per-session message and checkpoint retention is bounded by an explicit constant so the read model cannot grow without limit.
5. The projector decodes each payload with its own Schema rather than trusting the envelope.

## Notes

This is the piece that replaces `session_state_engine`, `projections` and `streaming_accumulator` at the in-memory level. Budget real time here; it is the heart of the rebuild.
